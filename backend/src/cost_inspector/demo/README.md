# Synthetic demo data

Every record in this directory is **fictional**. The files exist to demonstrate
AI Cost Inspector and are labelled *synthetic* everywhere in the app and in
exported reports. They describe no real customer, ticket, workload or bill.

They are generated by `scripts/generate_demo_data.py`. Costs are computed
exactly (decimal arithmetic) from **illustrative** per-million-token rates
listed in that script. Those rates are not any provider's pricing.

## Files

| File | Runs | What it demonstrates |
| --- | --- | --- |
| `support-agent-before.jsonl` | 1 | A baseline agent run with a deliberate repeated-call pattern (the same intent classification three times, the same format validation twice), short calls on a high-end model, and 8 model calls in one run. |
| `support-agent-after.jsonl` | 1 | The same synthetic task after three changes: classification on a smaller model, format validation in deterministic code (a tool with a reported cost of 0), and no repeated calls. |
| `nightly-digest-partial-telemetry.jsonl` | 2 | Incomplete telemetry: costs in two currencies (EUR and USD), calls without a reported cost, a self-hosted model with a known cost of 0, and a cross-run repeated signature. |

The measured change describes these two synthetic runs only. It is not a
production savings rate, and no output quality is measured.
