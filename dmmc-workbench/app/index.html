Starting the workbench in your browser

This page runs the workbench's Python code with Pyodide and evaluates OPA policies compiled to WebAssembly. Nothing is sent to a server; your actions are stored only in this browser.

The first visit downloads about 15 MB (less when the host compresses it) and takes a few seconds; later visits use the browser cache. Only one tab at a time can use the workbench.
